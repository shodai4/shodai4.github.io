1. 当サイトについて

当サイトは、個人でつくったアプリとツール、描いた絵、販売しているスタンプやZINEを紹介する場所です。ページは静的な HTML で、会員登録・ログインのしくみはありません。お問い合わせは、Google フォームで受け付けています。

2. 当サイトが受け取る情報

  • 閲覧の記録　当サイトは GitHub Pages（GitHub, Inc.）で公開しています。ページを開いたときに、IPアドレスやブラウザの種類、開いた日時といった情報が、ページを配信するために GitHub に記録されることがあります。当方がこれを見て、個人を特定することはありません。
  • お問い合わせのフォーム　フォーム（Google LLC が提供）で送っていただいた内容と、ご記入いただいた連絡先は、返信と記録のために保管します。やり取りが終わり、保管する必要がなくなったら削除します。ご本人からの依頼があれば、その時点で削除します。フォームの送信は Google のサービスを通して行われるため、入力内容は Google の規約とポリシーにも従って扱われます。
  • Cookie　当サイト自身は Cookie を設定していません。広告を表示するページでは、下記の第三者が Cookie を使用します。
  • 端末内の保存　当サイトのページは、ブラウザに情報を残す仕組み（localStorage など）も使っていません。

3. 広告の配信について

当サイトでは、Google LLC が提供する Google AdSense などの第三者配信事業者による広告を、表示することがあります。

  • 第三者配信事業者は、利用者の当サイトや他のサイトへの過去のアクセス情報に基づいて広告を配信するために、Cookie を使用することがあります。
  • Google が広告配信に Cookie を使用することにより、利用者が当サイトや他のサイトにアクセスしたときの情報に基づいて、当サイトや他のサイトに広告が配信されます。
  • Google による Cookie の使用と広告の仕組みについては、Google の広告に関するポリシーと規約をご覧ください。
  • Google のパートナーサイトでのデータの扱いは、パートナーサイトでのデータ使用にまとめられています。
  • 当方が、利用者の情報を広告主や第三者へ販売することはありません。

4. パーソナライズ広告を無効にする

過去のアクセス情報に基づく広告（パーソナライズ広告）は、次の方法で無効にできます。無効にしても、広告自体は表示されます。

  • Google の広告設定：https://adssettings.google.com/
  • 第三者配信事業者の Cookie の無効化：https://www.aboutads.info/choices/（英語）
